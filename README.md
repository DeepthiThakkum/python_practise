# Python Practice

Small scripts I wrote while learning Python fundamentals by following a beginner tutorial. Each file focuses on one concept.

## Contents

### 01-basics
| File | Topic |
|------|-------|
| `app.py` | First program: print, variables |
| `coursework_variables.py` | Strings, `len()`, indexing and slicing |
| `escape_sequences.py` | Escape sequences (`\"`, `\n`) |
| `formatted_strings.py` | Concatenation and f-strings |
| `string_methods.py` | `upper`, `lower`, `title`, `strip`, `find`, `replace`, `in` |
| `numbers.py` | Integers, floats, complex numbers, arithmetic operators, `math` |
| `type_conversion.py` | `input()`, `int()`, `float()`, `bool()`, `str()` |

### 02-control-flow
| File | Topic |
|------|-------|
| `true_false.py` | Truthy and falsy values |
| `comparison_operators.py` | `>`, `>=`, `==`, `!=` and string comparison |
| `logical_operators.py` | `and`, `or`, `not` |
| `conditional_statements.py` | `if` / `elif` / `else` |
| `ternary_operator.py` | One-line conditional expressions |
| `chaining.py` | Chained comparisons (`18 <= age < 65`) |
| `for_loops.py` | `for` loops with `range()` |
| `for_else.py` | `for ... else` |
| `iterables.py` | Iterating over ranges, strings and lists |
| `nested_loops.py` | Loops inside loops |
| `while_loops.py` | `while` loops |
| `infinite_loop.py` | Placeholder (empty) |

### 03-functions
| File | Topic |
|------|-------|
| `functions.py` | Defining functions, parameters, `return` |
| `keyword_arguments.py` | Default values and keyword arguments |
| `xargs.py` | Variable-length arguments (`*args`) |

## Running a script

```
python 01-basics/app.py
```

Requires Python 3.8 or newer.
